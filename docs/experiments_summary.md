# Experiments Summary

HM-16 established clean forced-choice scoring up to 2K. HM-17 extended the setup to 16K and showed a strong 3-bit advantage over uniform quantization on Qwen2.5-0.5B. HM-18 measured a focused 16K/3-bit system proxy and reported effective packed KV footprint. HM-19/HM-20 tested Qwen2.5-1.5B at 8K, showing that 3-bit is too aggressive while 4-bit is viable but uniform 4-bit remains a strong baseline.
